  ActualSales -> Sales Document Status, Product, Due Date, Order Date, Channel, Recorded Ship Date, Sales Line
  ActualPurchases -> Expected Receipt Date, Expected Ship Date, Purchase Document Status, Order Date, Product, Vendor
  ActualInventory -> Product, Location, Inventory Snapshot Date
  ActualWorkOrders -> Planned Start Date, Recorded End Date, Due Date, Actual End Date, Product, Actual Start Date
  ActualOperations -> Actual End Date, Scheduled Start Date, Location, Product, Scheduled End Date, Actual Start Date
  ActualBOM -> BOM Line, Assembly Product, Component Product, Unit
  ActualProductCostHistory -> Cost Period, Product
  ActualDemandDaily -> Product, Demand Date, Demand Rule

Phân cấp người dùng:
  Date / Calendar: Year -> Quarter -> Month -> Date
  Product / Products: Category -> Subcategory -> Product
